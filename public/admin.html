📘 LyriBop User Manual

LyriBop Operating Guide

Step-by-step instructions for creating, reviewing, delivering, and managing LyriBop songs.

Manual Sections

1. Introduction to LyriBop

LyriBop is a personalized-song system used to create, review, deliver, and manage custom songs for customers.

Purpose of This Manual

This manual provides the operating procedures used to process LyriBop orders from creation through final customer delivery.

LyriBop Operating Roles

OPERATOR ACTION: A step performed by the LyriBop administrator.

AUTOMATIC: A step performed automatically by LyriBop.

VERIFY: A checkpoint that should be confirmed before continuing.

WARNING: An important instruction that helps prevent an incorrect order or delivery.

The remaining chapters explain each part of the LyriBop workflow in detail.

2. LyriBop Admin Dashboard

The LyriBop Admin Dashboard is the main operating area for creating songs, processing customer orders, managing sellers, reviewing reports, and maintaining LyriBop business records.

Using the Admin Sidebar

OPERATOR ACTION: Select an item in the left sidebar to open that area of LyriBop.

The Admin sidebar includes:

  • Dashboard
  • Store Settings
  • Create Song
  • Customer Reviews
  • Active Orders
  • Closed Orders
  • Test Orders
  • Sellers
  • Accounting
  • Cost History
  • Reports
  • Store Display
  • Vendors
  • User Manual
  • Forms & Checklists

Working With Orders

OPERATOR ACTION: Use Dashboard and Refresh Orders to load the latest order information before beginning order processing.

VERIFY: Confirm the correct order number, customer, song recipient, status, and order details before performing work on an order.

AUTOMATIC: LyriBop moves orders through certain workflow stages automatically as lyrics, music, payment, and other processing steps are completed.

WARNING: Do not manually change an order status simply to force the normal LyriBop workflow forward. Verify the underlying step first.

3. Creating a Free LyriBop Song from Admin

Use Create Song when a LyriBop song needs to be created directly from Admin without requiring the customer storefront payment process.

Step 1 — Open Create Song

OPERATOR ACTION: Select Create Song from the Admin sidebar.

Step 2 — Enter the Song Information

Complete the customer and song information, including Your Name, Email, Song For, Occasion, Music Style, Mood, Lead Vocal, Vocal Style, Tempo, Duet, Instruments, Song Length, Story, and Special Message as applicable.

VERIFY: Review the spelling of names, email address, occasion, story details, special message, and all music selections before creating the preview.

Step 3 — Create the Preview

OPERATOR ACTION: Click Create 30-Second Preview.

AUTOMATIC: LyriBop creates the lyrics, saves the order, and generates a 30-second preview.

Step 4 — Review the Preview

VERIFY: Listen to the preview and confirm that the song matches the intended person, occasion, story, mood, and musical direction.

WARNING: Do not approve the full song until the preview and song information have been reviewed.

Step 5 — Refresh and Resume an Active Preview (If Needed)

AUTOMATIC: After the first preview has been successfully created, LyriBop saves the active Create Song session in the current browser session.

If the Admin page is refreshed, LyriBop restores the active preview, the most recently generated preview version, and the Create Song form information, including customer details, song settings, instruments, song length, story, and special instructions.

OPERATOR ACTION: After a refresh, continue working with the restored preview. Do not create a new order simply because the Admin page was refreshed.

Once the first preview exists, changes made to the Create Song form are automatically saved during the active browser session. Before the first preview is successfully created, form changes are not automatically saved for recovery.

OPERATOR ACTION: Use Create Another Preview when another preview version is needed. Each successfully created preview becomes the latest preview restored if the page is refreshed again.

VERIFY: Before approving the full song, confirm that the preview currently displayed is the version you want. If an alternate preview is active, LyriBop selects that version before generating the full song.

AUTOMATIC: After the full song is successfully approved, LyriBop clears the saved Create Song session and resets the form for the next song.

WARNING: Refresh/resume recovery applies to the current browser session. Do not rely on it as permanent recovery after the browser session has been closed.

Step 6 — Approve the Full Song

OPERATOR ACTION: Click Approve Full Song when the preview is acceptable.

AUTOMATIC: LyriBop generates the selected full-length song and moves the completed order to Ready.

Step 7 — Continue to Final QC

VERIFY: Locate the Ready order in Active Orders and complete the final lyric, audio, Customer Delivery, download, and print checks before sending the song to the customer.

Step 8 — Classify Test Songs Correctly

AUTOMATIC: Songs created through Admin Create Song are ordinary $0.00 orders by default. A $0.00 Admin-created order is not automatically classified as a test order.

OPERATOR ACTION: If an Admin-created song was made only for development or testing, locate the order and use Mark as Test. LyriBop then separates it from real orders in the Test Orders area.

VERIFY: Marking an order as a test changes its test classification; it does not delete the order. Test orders are excluded from business metrics where that filtering is implemented.

WARNING: Do not treat test classification as an order-deletion workflow. Use Mark as Test only when the order was created for testing rather than normal LyriBop use.

4. Revising Lyrics and Managing Song Versions

LyriBop allows lyrics to be revised while preserving earlier versions of the song for comparison.

Step 1 — Open the Order

OPERATOR ACTION: Locate the correct order in Active Orders and review the current lyrics.

Step 2 — Revise the Lyrics

OPERATOR ACTION: Select Revise Lyrics and enter the requested lyric changes.

AUTOMATIC: LyriBop creates a new lyric version while preserving the previous version.

Step 3 — Review the New Version

VERIFY: Open View Versions and review the revised lyrics carefully before generating new audio.

WARNING: A newly revised lyric version does not initially contain music. Review the lyrics first.

Step 4 — Generate Audio for the Revised Version

OPERATOR ACTION: Click Generate Version Audio for the revised version.

AUTOMATIC: LyriBop generates audio for that version and makes it available for playback and comparison.

Step 5 — Compare Versions

VERIFY: Compare the lyrics and audio of the available versions and determine which version should be used for the customer.

Step 6 — Select the Final Version

OPERATOR ACTION: Click Use This Version on the version selected for final delivery.

VERIFY: Confirm that the selected version is marked Current Version and that the same lyrics and audio appear in Admin and Customer Delivery before sending the order.

5. Trying Different Music

Use Try Different Music when the lyrics are correct but you want to hear the song in a different musical style.

Step 1 — Review the Current Song

VERIFY: Confirm that the current lyrics are correct before creating an alternate music version.

Step 2 — Select Try Different Music

OPERATOR ACTION: Locate the order in Active Orders and click Try Different Music.

Step 3 — Choose a Music Style

OPERATOR ACTION: Select the desired alternate music style from the available choices.

VERIFY: Confirm the selected style before continuing. The lyrics will remain the same.

Step 4 — Generate the Alternate Version

AUTOMATIC: LyriBop creates a new playable song version using the same lyrics with the selected music style. The original version is preserved.

Step 5 — Compare the Versions

VERIFY: Open View Versions and listen to the original and alternate versions before making a selection.

Step 6 — Select the Preferred Version

OPERATOR ACTION: Click Use This Version if the alternate version should become the customer version.

WARNING: Creating alternate music does not automatically make the new version the Current Version.

VERIFY: Before customer delivery, confirm that the intended version is marked Current Version and that its audio and lyrics appear correctly in Customer Delivery.

6. Final Quality Control, Customer Delivery & Closing an Order

Final Quality Control is the last operator review before a completed LyriBop song is sent to the customer.

Step 1 — Confirm the Order Is Ready

VERIFY: Locate the order in Active Orders and confirm that its status is Ready.

Step 2 — Review the Final Lyrics

OPERATOR ACTION: Open Show Lyrics. Verify names, occasion, story details, special message, spelling, and the overall lyric content.

Step 3 — Listen to the Full Song

OPERATOR ACTION: Click Play Song and listen to the full customer version.

VERIFY: Confirm the correct song version, complete audio, appropriate musical style, and acceptable overall playback.

Step 4 — Inspect Customer Delivery

OPERATOR ACTION: Open Customer Delivery before sending the delivery email.

VERIFY: Confirm the LyriBop Order Number, song title, full audio player, lyrics, Download MP3, and Print Lyrics.

If the order includes a second full version, verify that version and its download controls as well.

Step 5 — Test Customer Files

VERIFY: Play the customer-facing song, test the MP3 download, and open Print Lyrics before delivery.

NOTE: Use Print Preview and adjust the print scale when necessary so the lyrics fit the desired page layout.

Step 6 — Send to the Customer

OPERATOR ACTION: Return to the Admin order and click Send to Customer.

WARNING: Send to Customer sends the delivery email immediately. Complete Customer Delivery QC before clicking it.

VERIFY: Confirm that LyriBop reports the delivery email was sent successfully.

Step 7 — Mark the Order Delivered

OPERATOR ACTION: After successful delivery is verified, click Mark Delivered.

AUTOMATIC: The order moves from Active Orders to Closed Orders.

VERIFY: Confirm the closed order shows Delivered and retains the song, lyrics, version, and Customer Delivery controls for future reference.

7. Customer Delivery, Downloads & Reviews

The Customer Delivery page is the customer's private location for listening to the completed LyriBop song, viewing lyrics, downloading the MP3, printing lyrics, and leaving a review.

Customer Delivery Email

AUTOMATIC: When the operator uses Send to Customer, LyriBop sends the customer a delivery email containing the song title, LyriBop Order Number, and a private link to the Customer Delivery page.

VERIFY: The delivery email should identify the correct customer and song and provide access to the correct private delivery page.

Customer Delivery Page

The customer can use the delivery page to:

  • See the LyriBop Order Number.
  • Listen to the full LyriBop song.
  • Read the complete lyrics.
  • Download the song using Download MP3.
  • Print the lyrics using Print Lyrics.
  • Access a second full song when one was purchased.
  • Submit a customer review.

Downloads and Printed Lyrics

VERIFY: The MP3 download should contain the same selected song version that appears in the Customer Delivery player.

When printing lyrics, use the browser Print Preview and adjust the scale when needed for the preferred page layout.

Customer Reviews

Customers can leave a star rating, optional display name, and written review from the Customer Delivery page.

OPERATOR ACTION: Select Customer Reviews in Admin to review submitted customer feedback.

Admin displays the associated song, rating, review text, customer, order number, and review status.

VERIFY: Confirm that a submitted review is associated with the correct LyriBop order before performing any review management action.

8. Processing a Paid Customer Order

Paid customer orders begin on the LyriBop storefront and continue through Admin for final review, delivery, and closing.

Step 1 — Customer Creates a Preview

AUTOMATIC: The customer enters the song information and creates a 30-second preview. LyriBop saves the order and generates the preview.

Step 2 — Customer Completes Payment

The customer selects an available payment method and completes payment for the LyriBop song.

AUTOMATIC: After successful payment and full-song generation, LyriBop moves the completed order to Ready.

WARNING: Payment completion does not mean that the customer delivery email has already been sent.

Step 3 — Refresh Admin Orders

OPERATOR ACTION: Open Dashboard, use Refresh Orders, and then open Active Orders.

VERIFY: Locate the paid order and confirm the correct order number, customer, song recipient, order details, payment, and Ready status.

Step 4 — Perform Song Quality Control

VERIFY: Review the final lyrics and listen to the complete song. Confirm names, story details, special message, musical direction, and the selected Current Version.

Step 5 — Perform Customer Delivery QC

OPERATOR ACTION: Open Customer Delivery.

VERIFY: Check the LyriBop Order Number, title, full audio, lyrics, MP3 download, Print Lyrics, and any second full version included with the order.

Step 6 — Send the Delivery Email

OPERATOR ACTION: After all QC checks pass, return to the order and click Send to Customer.

WARNING: This sends the customer email immediately.

VERIFY: Confirm that LyriBop reports the email was sent successfully and, when possible, verify the received delivery email.

Step 7 — Close the Order

OPERATOR ACTION: Click Mark Delivered only after successful customer delivery has been verified.

AUTOMATIC: The order moves to Closed Orders with a Delivered status.

Step 8 — Verify the Sale

VERIFY: Use the appropriate LyriBop report to confirm that the paid order is included in the business sales records.

9. Reports and Accounting

LyriBop provides reporting and accounting tools for reviewing sales activity, customer activity, seller referrals, and business records.

Opening Reports

OPERATOR ACTION: Select Reports from the Admin sidebar.

Report periods can be selected using Today, Week, Month, or a Custom date range.

VERIFY: Always confirm the displayed start and end dates before using report totals.

Sales Report

The Sales Report summarizes paid orders for the selected period, including paid order count, total sales, average order value, and individual paid-order activity.

VERIFY: Use the Sales Report to confirm that a successfully paid customer order appears in the business sales records.

Customer Report

The Customer Report provides customer activity information for the selected period, including unique customers and repeat or returning customer information.

Seller Report

The Seller Report summarizes LyriBop sellers and referral activity, including seller paid orders and seller sales totals.

VERIFY: When reviewing a referred order, confirm that the correct seller or referral code is associated with the order before relying on seller totals.

Accounting and Cost Records

OPERATOR ACTION: Use Accounting and Cost History from the Admin sidebar when reviewing LyriBop financial and cost records.

Printing Reports

LyriBop provides print controls for the individual reports. Use the appropriate Print Report control after confirming the report type and date range.

WARNING: Report totals should always be reviewed together with the selected report period. A correct total for one date range may not represent activity outside that period.

10. Troubleshooting and Recovery

Use these procedures when an order does not appear to be following the normal LyriBop workflow.

Order Information Appears Out of Date

OPERATOR ACTION: Return to Dashboard and use Refresh Orders, then reopen the appropriate order area.

VERIFY: Check the order number and current status again before taking further action.

Order Is Not Ready

VERIFY: Review the workflow indicators for Lyrics Created, Music Generated, and Ready to determine which normal processing step has not been completed.

WARNING: Do not manually change an order status simply to force the order forward. Verify and correct the underlying workflow step first.

Revised Lyrics Have No Audio

A newly revised lyric version may initially contain lyrics without music.

OPERATOR ACTION: Open View Versions, review the revised lyrics, and use Generate Version Audio for the version that needs music.

Wrong Song Version Appears

VERIFY: Open View Versions and confirm which version is marked Current Version.

OPERATOR ACTION: Use Use This Version when a different completed version should become the customer version.

Recheck Admin playback and Customer Delivery after changing the Current Version.

Customer Delivery Does Not Look Correct

WARNING: Do not use Send to Customer until Customer Delivery QC passes.

VERIFY: Check the order number, song title, audio, lyrics, MP3 download, Print Lyrics, and any purchased second version.

Delivery Email Problem

If LyriBop does not report that the delivery email was sent successfully, keep the order open and investigate the delivery issue before marking the order Delivered.

WARNING: Do not use Mark Delivered until successful customer delivery has been verified.

Print Lyrics Does Not Fit the Preferred Layout

OPERATOR ACTION: Use the browser Print Preview and adjust the print scale as needed. Longer songs may require a smaller scale to fit the desired number of pages.

Preserving Order History

VERIFY: Before deleting, replacing, or otherwise changing important order information, confirm that the action will not remove information needed for customer support, reporting, or future order reference.

11. Forms & Checklists

LyriBop forms and checklists provide a consistent way to document quality-control checks during song production and customer delivery.

OPERATOR ACTION: Select Forms & Checklists from the Admin sidebar to open the printable operational forms.

11.1 Song Version QC Checklist

Use this checklist when comparing revised lyrics, regenerated audio, or alternate music versions before selecting the final Current Version.

11.2 Final Order & Delivery QC Checklist

Use this checklist when an order reaches Ready status. Complete the final lyric, audio, version, Customer Delivery, download, print, email, and delivery checks before closing the order.

11.3 Customer Delivery QC Checklist

Use this checklist to verify the customer-facing delivery page, including the order number, song title, audio, lyrics, MP3 download, Print Lyrics, and any purchased second full version.

Completing a Checklist

Record the Order Number, Song For, Date, and Reviewed By information before beginning the checklist.

Complete each checkbox in workflow order and record the final selected version when applicable.

Use the Notes area to document corrections, unusual conditions, or follow-up work.

VERIFY: Complete the Completed By, Date, and Signature/Initials fields when the checklist is finished.

WARNING: A checklist supports the LyriBop workflow; it does not replace listening to the song, reviewing the lyrics, or verifying Customer Delivery before sending an order.

LyriBop Workflow

Order Created → Lyrics Created → Music Generated → Ready → Customer Delivery → Delivered
