# Create Advertisement

Open the existing local Advertising Dashboard, then Create Advertisement below Posting History. Refresh the dashboard if the link is missing. No Render deployment is needed.

Choose one of 14 approved backgrounds, edit the headline, message, call to action and website, then select Square or Story. Download Ad creates a PNG (1080×1080 or 1080×1920). Add a clickable website link separately when posting.

Save Design stores a new named copy in this browser on this Mac. Load restores it; Delete removes the selected copy after confirmation. Clearing browser data removes these saves. Downloads remain ordinary files. No automatic posting, cloud sync or paid image generation happens in this editor.
