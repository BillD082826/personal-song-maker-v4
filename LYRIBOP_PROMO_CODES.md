# LyriBop single-use offer codes

Prepared November 10, 2026. Not live until deployment is approved and verified.

Admin → Offer Codes creates 1–100 unique codes per batch: one free complete song or 1–99% off. Each code is single-use. Optional expiration uses the Admin's local time; an empty date means no expiration. Optional batch label is internal. Copy/download the generated list before leaving: only hashes and final four characters are stored. Full codes cannot be retrieved later. Anyone holding a code can redeem it; no recipient restriction.

Customer: create a preview, select one song, enter the code and Apply Code. Original price, discount and final total appear. Complete Free Order redeems a free code at $0 without a payment provider. Percentage codes use the existing PayPal/Venmo/card checkout with a server-calculated price. Album cover and printable lyrics remain included. Extra-version upgrades and stacking are excluded; remove the extra-version selection first. Referral association is retained and any commission uses the actual discounted order price, not the undiscounted price.

A quote does not reserve or use a code. Starting a discounted checkout locks the code to that order and freezes its total. Only verified PayPal capture marks it redeemed. Free checkout updates order completion and code redemption atomically. Concurrent use for another order fails. Repeating a completed free request on the same order returns its prior success without another redemption; confirmation email uses the existing durable guard.

Held codes are never automatically released, including abandoned, canceled or uncertain PayPal requests. They remain usable only for the original order with its original code, even after the offer expiry. This conservative first version avoids reissuing a code whose payment could still complete. Available codes can be disabled. Redeemed or held codes cannot be reset, and refunds do not automatically reissue codes. Reclaiming held codes requires a future verified provider-cancellation workflow; do not manually reset state.

History shows the latest 1,000 code endings, offer, batch label, status, expiration and linked order. No production codes have been issued by this implementation work. Existing orders are not changed by installing storage.

Implementation: additive promo_codes table; orders promo_id, promo_base_amount, promo_completed_at. Admin Basic authentication plus exact Origin on mutations. Customer preview token, exact Origin and existing payment rate limit. Codes use 96 random bits and SHA-256 storage. SQL row locks and transactions serialize claims. Prices are calculated in integer cents; client totals are ignored. No secret/code logging. Regular PayPal checkout freezes the price before provider access; extra-version writes also reject a checkout that began concurrently.
